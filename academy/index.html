Questions

Do I need to install anything?

No. Lessons, the editor, the code runner, and the grader all run in your browser. Works on any modern browser — even a Chromebook or tablet.

What language will I learn?

JavaScript — the language of the web. The concepts transfer everywhere: variables, loops, functions, data structures, async, and design thinking are the same in Python, Java, or Rust.

Is the Free plan actually free?

Yes — the entire Code Basics track, the playground, and progress tracking are free forever, no card required.

What is the Code Desk?

An Advanced-tier feature: describe what you're building and where you're stuck, and a mentor responds with guidance. It's like having a senior engineer on call while you build your own project.

What makes Premium different from Advanced?

Advanced helps you build. Premium teaches you to think — masterclasses on how staff engineers read code, reason about complexity, apply design patterns, test, and review like the best in the industry.
